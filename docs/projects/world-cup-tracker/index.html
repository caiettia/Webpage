World Cup Tracker

Automated prediction-pool scoring with leaderboard and bracket views.

The problem

Manually scoring tournament prediction pools in spreadsheets makes standings and bracket updates repetitive.

What I built

I built a Python pipeline to sync standings, score group and knockout picks, and generate JSON leaderboard snapshots for a static React frontend.

The result

Entrants can browse the leaderboard, bracket, and third-place race through one mobile-friendly interface.
